# Protein Design: RFdiffusion + ProteinMPNN Pipeline

## Overview

This skill provides the standard computational protein design pipeline used in the field today. The workflow follows three stages:

1. **RFdiffusion** generates novel protein backbones (3D coordinates) via structure denoising diffusion
2. **ProteinMPNN** designs amino acid sequences that fold into the generated backbones
3. **AlphaFold2 or ESMFold** validates that designed sequences are predicted to fold correctly (self-consistency check)

This pipeline has been experimentally validated across multiple wet-lab studies. RFdiffusion designs have been crystallized and shown to match computational predictions with sub-angstrom accuracy. ProteinMPNN achieves 52.4% native sequence recovery on held-out structures, significantly outperforming previous physics-based methods like Rosetta.

## Core Capabilities

### 1. De Novo Protein Design

Generate entirely new protein backbones with no template.

**When to use:**
- Creating novel protein folds from scratch
- Generating proteins of a specific length
- Exploring the space of designable proteins

**Basic usage (RFdiffusion):**

```bash
# Generate 10 novel 150-residue protein backbones
python scripts/run_inference.py \
    'contigmap.contigs=[150-150]' \
    inference.output_prefix=outputs/denovo \
    inference.num_designs=10
```

### 2. Binder Design

Design protein binders that target a specific interface on a target protein.

**When to use:**
- Designing therapeutic binders against a target
- Engineering protein-protein interactions
- Creating biosensors that bind specific epitopes

**Basic usage:**

```bash
# Design 100-residue binders targeting hotspot residues on chain A
python scripts/run_inference.py \
    'contigmap.contigs=[B1-100/0 100-100]' \
    inference.input_pdb=target.pdb \
    'ppi.hotspot_res=[A30,A33,A34]' \
    inference.output_prefix=outputs/binder \
    inference.num_designs=10
```

The contig string `[B1-100/0 100-100]` means: keep chain B residues 1-100 from the target, add a chain break (`/0`), then generate a new 100-residue binder chain. Hotspot residues define which target residues the binder should contact.

### 3. Motif Scaffolding

Incorporate a functional motif (e.g., active site, binding epitope) into a new protein scaffold.

**When to use:**
- Transplanting an enzyme active site into a new fold
- Scaffolding a binding epitope for vaccine design
- Preserving key functional residues while redesigning the surrounding protein

**Basic usage:**

```bash
# Scaffold residues 10-25 of chain A with flanking regions
python scripts/run_inference.py \
    'contigmap.contigs=[10-40/A10-25/10-40]' \
    inference.input_pdb=motif.pdb \
    inference.output_prefix=outputs/scaffold \
    inference.num_designs=10
```

The contig `[10-40/A10-25/10-40]` means: generate 10-40 new residues, then place residues 10-25 from chain A of the input PDB, then generate 10-40 more new residues.

### 4. Symmetric Assembly Design

Generate symmetric protein oligomers (cyclic, dihedral, tetrahedral).

**When to use:**
- Designing nanocages and symmetric assemblies
- Creating multivalent display scaffolds
- Engineering symmetric enzyme complexes

**Basic usage:**

```bash
# Design a C3-symmetric trimer
python scripts/run_inference.py --config-name symmetry \
    inference.symmetry=c3 \
    'contigmap.contigs=[120-120]' \
    inference.output_prefix=outputs/symmetric \
    inference.num_designs=5
```

### 5. Sequence Design with ProteinMPNN

Design sequences for any protein backbone, whether generated by RFdiffusion or obtained experimentally.

**When to use:**
- Designing sequences for RFdiffusion-generated backbones
- Redesigning sequences for existing structures
- Multi-state or symmetric sequence design

**Basic usage:**

```bash
# Parse the PDB structure
python helper_scripts/parse_multiple_chains.py \
    --input_path=backbone.pdb \
    --output_path=parsed_chains.jsonl

# Design 8 sequences at temperature 0.1
python protein_mpnn_run.py \
    --jsonl_path parsed_chains.jsonl \
    --out_folder outputs/sequences \
    --num_seq_per_target 8 \
    --sampling_temp "0.1" \
    --seed 42
```

## Standard Workflow

The complete pipeline for any design task:

```
1. RFdiffusion (backbone generation)
       |
       v
2. ProteinMPNN (sequence design, multiple sequences per backbone)
       |
       v
3. AlphaFold2 / ESMFold (structure prediction of designed sequences)
       |
       v
4. Filter by: pLDDT > 70, scRMSD < 2.0 A (self-consistency)
       |
       v
5. Experimental validation (expression, binding, crystallography)
```

**Self-consistency check:** For each designed sequence, predict its structure with AlphaFold2 or ESMFold. Compare the predicted structure to the designed backbone. Designs where the predicted structure closely matches the design (scRMSD < 2.0 angstroms) and has high confidence (pLDDT > 70) are considered successful.

## Key RFdiffusion Parameters

| Parameter | Description | Example |
|-----------|-------------|---------|
| `contigmap.contigs` | Defines chain topology and residue ranges | `[100-100]`, `[10-40/A10-25/10-40]` |
| `inference.input_pdb` | Input PDB for motif scaffolding or binder design | `target.pdb` |
| `inference.output_prefix` | Output path prefix | `outputs/design` |
| `inference.num_designs` | Number of backbones to generate | `10` |
| `ppi.hotspot_res` | Target hotspot residues for binder design | `[A30,A33,A34]` |
| `inference.ckpt_override_path` | Override model checkpoint | `models/Complex_base_ckpt.pt` |
| `diffuser.T` | Number of diffusion timesteps | `50` (default) |
| `diffuser.partial_T` | Partial diffusion steps (for diversification) | `20` |
| `denoiser.noise_scale_ca` | Translation noise scale | `0.5` |
| `denoiser.noise_scale_frame` | Rotation noise scale | `0.5` |

## Key ProteinMPNN Parameters

| Parameter | Description | Example |
|-----------|-------------|---------|
| `--pdb_path` | Input PDB file | `backbone.pdb` |
| `--jsonl_path` | Parsed chain data | `parsed.jsonl` |
| `--out_folder` | Output directory | `outputs/` |
| `--num_seq_per_target` | Sequences per backbone | `8` |
| `--sampling_temp` | Sampling temperature (0.1-0.3 recommended) | `"0.1"` |
| `--seed` | Random seed | `42` |
| `--batch_size` | Batch size (adjust for GPU memory) | `1` |
| `--use_soluble_model` | Use soluble-protein-trained weights | (flag) |
| `--ca_only` | Use CA-only model | (flag) |

## Benchmark Context

- **RFdiffusion:** Designs experimentally validated with sub-angstrom accuracy in crystal structures. Successful binder designs against therapeutically relevant targets (e.g., influenza hemagglutinin, PD-L1, insulin receptor).
- **ProteinMPNN:** 52.4% native sequence recovery on held-out test set. Designed sequences express and fold at significantly higher rates than Rosetta-designed sequences.
- **Pipeline success rates:** Typically 10-30% of designed binders show binding in experimental screening, depending on target difficulty.

## Alternative Tools

| Tool | Strengths | When to prefer |
|------|-----------|----------------|
| **Chroma (generatebiomedicines)** | Programmable conditioning, natural-language constraints | Need flexible conditioning beyond structural motifs |
| **ProGen / ProGen2** | Family-specific protein generation from sequence only | Have family-level sequence data, no structure needed |
| **ESM3** | Multimodal (sequence + structure + function), single model | Want integrated sequence-structure-function generation |
| **EvoDiff** | Sequence-space diffusion, no structure required | Need sequence-only generative model |
| **ProteinMPNN alone** | Sequence design for existing backbones | Already have a backbone, only need sequence design |
| **Rosetta (classic)** | Physics-based energy functions, established protocols | Need energy-based scoring or specific Rosetta protocols |

## When to Use This Skill

**Use when:**
- Designing de novo protein backbones from scratch
- Engineering protein binders against specific targets
- Scaffolding functional motifs into new protein folds
- Designing symmetric protein assemblies
- Running the standard backbone-generation-then-sequence-design pipeline

**Do NOT use when:**
- You only need sequence design for an existing backbone (use ProteinMPNN alone or the ESM skill for inverse folding)
- You need natural-language or programmatic conditioning (use Chroma)
- You need sequence-only generation without structural constraints (use ProGen or EvoDiff)
- You need structure prediction only (use AlphaFold2 or ESMFold)
